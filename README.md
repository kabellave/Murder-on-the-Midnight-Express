Mystery Train – Interactive Detective Game

Welcome aboard the Mystery Train, an interactive narrative game where every choice matters and every clue brings you closer to the truth.
This project blends storytelling, investigation, and UI-driven exploration to create a short but engaging detective experience.

🎮 About the Game

Mystery Train is an interactive mystery experience where you take on the role of a passenger trapped on a train after a strange incident.
You must examine rooms, gather evidence, listen to characters, and make choices that shape the story.
Your goal is simple: uncover what happened before time runs out.

🧩 Features

Interactive storytelling with branching dialogue.

Evidence system that stores clues you collect.

Suspicion meter that reacts to your choices.

Room-based exploration using clickable UI sections.

Atmospheric sound support (music, narration, and trigger-based sound cues if implemented).

Modular code structure (HTML, CSS, JavaScript / React depending on your version).

🚀 How to Run the Game
If using React

Install dependencies:

npm install


Start the development server:

npm run dev


Open your browser and go to:

http://localhost:5173

If using plain HTML/CSS/JS

Simply open index.html in your browser.
